# 🚀 Copilot カスタムコマンド利用ガイド
開発メンバー向けドキュメント

このプロジェクトでは、GitHub Copilot Chat のカスタムプロンプトを `.github/prompts/` 以下に配置しており、以下のような **開発効率を高める専用コマンド** を利用できます。

- 変更差分から高品質なコミットメッセージを自動生成
- 指定ファイルのコード内容を初心者向けに解説

---

# 📂 1. カスタムコマンドの場所

カスタムコマンドは以下のディレクトリで管理されています。

```text
.github/
└─ prompts/
   ├─ commit-message.prompt.md
   ├─ explain-code.prompt.md
   └─ pr-summary.prompt.md
```

**使用方法:** Copilot Chat の画面で `/commit-message` や `/explain-code` と入力して使用します。

---

# ✨ 2. 利用可能なカスタムコマンド一覧

## ① `/commit-message`

### 🎯 目的
現在の `git diff` をもとに、**Conventional Commits 形式の質の高いコミットメッセージを自動生成**します。

### 🧩 特徴
- `feat`, `fix`, `refactor` などを使ったメッセージを生成
- 「追加」「修正」「削除」項目を箇条書き整理
- 日本語でわかりやすい説明つき
- 背景が推測できる場合は簡単に補足

### 📝 出力イメージ

```yaml
feat: ○○機能を追加

追加
...

修正
...

削除
...
```

> **⚠️ 注意**
> `.prompt.md` では `git diff` を自動取得できないため、Copilot が差分を読み取れない場合は**手動で diff をチャットに貼り付ける**必要があります。

<br>

## ② `/explain-code`

### 🎯 目的
指定したファイルのコード内容を、**初心者にもわかる形で丁寧に解説**します。

### 🧩 内容
- ファイルが何をするコードか
- 主な関数の処理の流れ
- 専門用語をできる限り控えた説明

---

# 🛠️ 3. カスタムコマンドの追加方法

1. `.github/prompts/` に以下の形式でファイルを新規作成します。

```yaml
---
agent: 'agent'
description: 'このコマンドの説明'
model: 'Grok Code Fast 1'
tools: ['search', 'todos']
---

（ここにコマンド内容を書く）
```

### ✏️ `.prompt.md` 作成時の注意点

| 項目 | 使用可能？ | 補足 |
| :--- | :--- | :--- |
| **Meta情報**<br>(agent / description / model / tools) | ⭕ 使える | ファイル先頭のYAMLブロックで定義 |
| **Context** | ❌ 使用不可 | Promptファイル内では定義できません |
| **任意のテンプレート** | ⭕ 使用可能 | 本文に自由に記述可能です |

---

# ⚠️ 4. `.prompt.md` の制約

`.prompt.md` は GitHub Copilot Chat の GitHub 用設定のため、VS Code のローカル機能とは異なる以下の制約があります。

| やりたいこと | 可能？ | 補足 |
| :--- | :--- | :--- |
| **git diff を自動で渡す** | ❌ 不可 | VS Code のカスタムコマンドのみ可能 |
| **任意のファイルを自動参照** | ❌ 不可 | 手動で貼り付けるか、チャットへドラッグが必要です |
| **固定テンプレートを提供** | ⭕ 可能 | `.prompt.md` で自由に記述できます |

---

# 💡 5. チームでの推奨ワークフロー

1. **変更を行う**
2. Copilot Chat で **`/commit-message`** を実行
3. 生成されたメッセージを `git commit -m` に貼り付け
4. PR を作成
5. わからないコードは **`/explain-code`** で内容を理解
6. **レビュー効率向上** 🚀
